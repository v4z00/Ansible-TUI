Ansible TUI changelog · German release notes in CHANGELOG.de.txt

0.3.1 – Documentation and catalog language
English README, installation guide, screen tour and API reference. New standalone
projects can choose a catalog language at setup. Existing configurations retain
their choice and legacy projects without one still use German.

0.3.0 – 2026-11-26
Controller descriptions are available in German and English. The Docker adapter
recognizes both summary prompts. Removing orphaned stacks requires confirmation.

0.2.3 – 2026-11-24
Fixed job tracking and cleanup on tmux 3.5a. Docker tabs retain their position
while loading. The tmux status bar shows how to return from a job terminal.

0.2.2 – 2026-11-24 · My first GitHub release
Ansible TUI received its own GitHub release and consistent naming across the UI,
CLI help and documentation.

0.2.1 – 2026-11-24
One Linux installer handles numeric release tags. The setup command reports
updates, verifies the build and switches releases atomically.

0.2.0 – 2026-11-24
Independent checkout, project initialization and Ansible checks. Regular projects
can preview a playbook with a limit and check mode. Docker, tmux and SSH gained
separate switches. Direct execution records results in local history.

0.1.7 – 2026-11-22
Foreground/background preview, tmux session listing and idle-session cleanup.
Closing the UI detaches its clients while jobs continue. Finished failures can
be acknowledged. Completed job logs, panes and events can be cleared separately.

0.1.6 – 2026-11-22
Prefix navigation, explicit filtering and Ctrl shortcuts. The status bar explains
how to return from tmux. Optional prompt handling for supported linear Docker
deployments can acknowledge the Enter-only summary or focus real input requests.

0.1.5 – 2026-11-22
Forms derive target suggestions from the registered playbooks and actual inventory.
Settings can disable suggestions or Docker polling, change the group or interval,
and clear the in-memory inventory cache after preview.

0.1.4 – 2026-11-22
Consistent keyboard focus across actions and dialogs, improved text editing,
color and count indicators on Docker tabs and brief completion notifications.

0.1.3 – 2026-11-22
Docker deployment hosts come from the configured inventory group and its
children. Select a host from tabs or a searchable list. Asynchronous polling,
timestamps and generation checks keep slow or outdated results separate.

0.1.2 – 2026-11-22
German terminal labels gained ASCII spelling. Forms display option names, host
and group selection and typed templates. Execution values retain their original
spelling and type.

MJH 0.1.1 – 2026-11-18
Mouse hit areas and scrolled table rows align with drawing. New sidebar and
actions, clickable forms and a safe default in confirmation dialogs. The service
uses project-local tools and handles inventory hosts without separate hostvars.
Updates preserved existing units, state and releases used by running jobs.
